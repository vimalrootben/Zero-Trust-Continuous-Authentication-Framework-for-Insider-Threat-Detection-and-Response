# ZTA / Wazuh Baseline Document

- **Platform Name**: ZTA (Zero Trust Architecture)
- **Base EDR Engine**: Wazuh Fork
- **Wazuh Core Version**: `5.1.0` (Stage: `alpha0`)
- **Version Metadata File**: `VERSION.json`
- **Target OS Support**: Windows 10/11 / Windows Server (Agent), Linux (Manager/Engine)
- **Primary Telemetry Sources**:
  - Windows Event Log (`Security`, `System`, `Application`)
  - Microsoft Sysmon (Process Creation, Network Connections, Registry Modifications, Driver Load, LSASS Access)
  - Windows PowerShell Operational Logs (ScriptBlock Logging / Event ID 4104)

---

| Component | Status | Details |

## Known Baseline Integration Hook
The ZTA Event Adapter hooks into the alert output stream generated by the analysis engine (e.g. `alerts.json` or socket output), normalizing alerts into canonical `ZTAEvent` structures.
